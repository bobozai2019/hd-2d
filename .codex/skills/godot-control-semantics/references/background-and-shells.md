# 背景与外壳

当 HTML 区块主要是壳、包裹层或装饰性外壳时使用本文件。

## `Control`

- 是什么：灵活的基础 UI 节点。
- 自动行为：默认不进行容器子排列。
- 适合场景：需要中性壳、手动定位或混合内容的父包裹层。
- 最常见误用：在区块实际需要容器行为时，让所有结构过于松散。
- HTML 映射问题：这个区块是否主要是中性包裹层，而非布局引擎？

## `Panel`

- 是什么：简单的面板式视觉控件。
- 自动行为：不是容器布局管理器。
- 适合场景：需要样式化的视觉表面，但不想将节点变成内容排列容器。
- 最常见误用：跳过它直接用 `PanelContainer`，而 HTML 区块只是视觉壳。
- HTML 映射问题：这只是一个视觉板或卡片面吗？

## 外壳模式

当 HTML 区块有视觉框和内部内容时，建议分离职责：

- 视觉壳节点
- 内部布局/内容节点

典型安全模式：

- `Panel -> Body`
- `Control -> 装饰节点 + Body`
- 当区块确实是内容面板时：`PanelContainer -> Shell -> Body`

选择前先问：

- 这个节点是否需要排列子元素？
- 还是它只需要在视觉上存在，由另一个子节点处理布局？
