# 内容与资产

当 HTML 区块主要是显示内容而非排列兄弟布局时使用本文件。

## `TextureRect`

- 是什么：图像/美术承载器。
- 自动行为：显示纹理，无布局逻辑。
- 适合场景：HTML 元素本质上是美术、图标、标记、徽记美术或导出资产内容。
- 最常见误用：把它当作通用布局包裹层。
- HTML 映射问题：这个节点是在显示资源，还是在排列其他节点？

## `Label`

- 是什么：简单文本显示。
- 自动行为：显示文本；尺寸取决于字体和内容规则。
- 适合场景：HTML 元素确实是文本内容。
- 最常见误用：用文本作为类图像符号、进度条、图标条或视觉计数器的长期替代。
- HTML 映射问题：这是语义文本，还是伪装成文本的视觉内容？

## `RichTextLabel`

- 是什么：格式化文本显示。
- 自动行为：处理比 `Label` 更丰富的内联格式。
- 适合场景：HTML 内容本质上仍是文本，但需要内联强调或格式化。
- 最常见误用：用它来避免拆分文本/美术职责。
- HTML 映射问题：丰富性是文本层面的，还是某些部分应该拆分为独立节点？

## 常见 HTML 到 Godot 内容场景

- 进度条填充：
  通常是外壳内的内容/填充元素，不是主布局驱动。
- 徽记或图标条：
  通常是内容集群；不要让它变成主导结构块。
- 计数器或符号行：
  判断它们是语义文本还是视觉指示器。如果行为像指示器，按内容视觉处理，而非普通段落。
- 美术槽位：
  将槽位壳与渲染资产的内容节点分离。
