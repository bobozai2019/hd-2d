# 阶段 4：氛围、特效、相机和性能

阶段状态： `[x]` 已完成

## 目标

在 P0 稳定和正式地图接入之后，增强 HD-2D 的表现力：粒子、局部雾、Glow 源、简单技能特效、动态光、镜头演出和性能压力验证。

本阶段只做能明显提升画面的表现增强。任何效果如果破坏角色清晰度、排序稳定或地图可读性，应降低强度或移出默认模板。

## 范围

包含：

- 灰尘、火星、萤火虫、烟雾等低强度粒子。
- 局部雾 Plane 或 Sprite3D 雾层。
- 火把、灯笼、水晶、魔法阵等 Glow 样本。
- 简单技能或点击反馈特效。
- 动态局部光测试。
- 镜头轻推、聚焦、震动等轻量演出验证。
- 多角色、多灯光、多粒子性能压力测试。

不包含：

- 不做完整战斗系统。
- 不做大规模技能库。
- 不把体积雾设为默认必需项。
- 不引入复杂昼夜循环。

## [x] 任务 4.1：建立 VFX 根节点和样本

实验场和正式 Run 地图都应有清晰 VFX 容器：

```text
VfxRoot
├── AmbientParticles
├── GlowSources
├── SkillSamples
├── FogPlanes
└── DynamicLights
```

每类样本只保留能说明问题的最小数量：

- 1 个环境粒子。
- 1 个局部雾层。
- 1 个 Glow 发光源。
- 1 个简单技能/点击反馈特效。
- 1 个动态光样本。

## [x] 任务 4.2：粒子氛围验证

优先测试：

- 灰尘：低速、低透明度，服务空气感。
- 火星：只在火把或高光源附近出现。
- 萤火虫：低数量、慢速，避免抢节点可读性。
- 烟雾：贴近火源或洞穴，不覆盖主体。

通过标准：

- 粒子让画面更活，但不遮挡角色和可点击节点。
- 粒子材质和排序不破坏 Sprite3D 角色显示。
- 关闭粒子后画面仍成立。

## [x] 任务 4.3：局部雾和 Glow 验证

局部雾优先使用低成本方案：

- 半透明 Mesh Plane。
- Sprite3D 雾片。
- 少量粒子烟雾。

Glow 源应绑定到可解释对象：

- 火把。
- 窗户。
- 水晶。
- 魔法阵。
- 节点激活反馈。

通过标准：

- Glow 可见但不过曝。
- 雾拉开层次但不洗灰主体。
- 前景雾不和角色排序打架。

## [x] 任务 4.4：简单技能和点击反馈样本

制作一个最小特效样本：

```text
点击 available 节点
  -> 节点轻微发光/脉冲
  -> 短暂粒子或 Sprite3D 特效
  -> 如果性能预算允许，局部 OmniLight 在 0.15 秒内闪烁一次
```

要求：

- 特效持续时间短。
- 特效可关闭或降级。
- 不改变 Run 状态逻辑。
- 不遮挡 HUD。
- 如果局部光导致排序、性能或过曝问题，默认模板只保留节点脉冲和短暂粒子。

## [x] 任务 4.5：相机演出验证

只做轻量相机演出：

- 进入节点时轻微推近。
- 战斗节点选中时短暂聚焦。
- Boss/事件节点可轻微压低环境亮度或改变局部光。
- 震动只用于短促反馈，不用于常态地图浏览。

通过标准：

- 相机演出不会让用户迷路。
- 演出结束后能回到稳定可读的地图视角。
- 任何自动相机动作都不破坏手动相机控制。

## [x] 任务 4.6：性能压力测试

建立压力场景或测试 profile：

```text
30 个 Sprite3D/AnimatedSprite3D
20 个地块
8 个局部灯
3 组粒子
3 层透明雾/特效
Glow + Fog + DOF 开启
```

记录：

- 平均 FPS。
- 最低 FPS。
- 粒子数量。
- 光源数量。
- 透明对象数量。
- 截图是否仍清晰。

如果性能不稳定，优先降级：

1. 粒子数量。
2. 局部光数量。
3. 透明雾层数量。
4. DOF 和 Glow 强度。
5. Shader 复杂度。

## 阶段完成标准

- 实验场和正式地图都有最小 VFX 样本。
- 粒子、雾、Glow、动态光和简单特效没有破坏 P0 排序。
- 相机演出轻量可控。
- 性能压力测试有记录和建议上限。
- 默认视觉模板仍保持克制，不因增强效果变成糊屏。
