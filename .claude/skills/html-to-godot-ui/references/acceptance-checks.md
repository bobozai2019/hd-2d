# 验收检查

本文件不定义整页验收体系。它只生成由所选控件语义产生的后续检查项。

只包含由当前风险直接隐含的检查项。

不要用页面级相似性替代这些检查。页面可以大致到位，但高风险组件在结构上仍然错误。

## 组件检查类型

- 进度条：
  验证短条与主导视觉权重的对比、壳/填充拆分、以及厚度/长度比例。
- 徽记或图标条：
  验证它保持为辅助元素，而非布局驱动。
- 计数器或符号行：
  验证它被一致地视为真正文本或视觉指示器。
- 标题/正文间距：
  验证壳不会强制文本块进入错误的层级或权重。
- 美术槽位：
  验证壳、padding 和内容渲染分离清晰。

## 规则

不要生成通用检查清单。

对于每个高风险组件，只生成：

- 为什么存在这项检查
- 必须保持的视觉比例或语义边界是什么
- 如果不单独检查此组件，哪些页面级匹配会具有误导性
