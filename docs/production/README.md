# 量产规范索引

版本：v0.1
日期：2026-06-15
适用范围：Godot 4.6 HD-2D 项目进入量产后的代码、UI、资产和验证工作。

## 目标

本目录把散落在 `CLAUDE.md`、`.claude/knowledge/` 和项目技能里的经验收束成可执行规范。

量产阶段的默认原则：

- 规则优先写成文档，再沉淀成脚本校验。
- 资源格式、UI 结构和验证命令必须清楚。
- 历史遗留允许分批迁移，但新增内容应按本目录规范执行。
- 本目录规范与旧文档冲突时，除非用户另有说明，以本目录为量产准则。

## 文件

- `01-code-standard.md`：GDScript、架构边界、系统接入和调试输出规范。
- `02-ui-standard.md`：Godot 原生 UI 制作、主题、场景拆分和截图验收规范。
- `03-asset-pipeline.md`：图片资产、generated/source/sheet/import 文件管理规范。
- `04-repo-hygiene.md`：仓库清理、日志截图、旧实现归档和提交前检查规范。

## 迁移节奏

推荐顺序：

1. 资源数据先进入脚本校验，防止量产扩表时破坏运行。
2. UI 先统一主题 token 和场景拆分方式，再处理视觉细节。
3. 代码层逐批消除无返回类型函数、生产 `print()`、UI 脚本 `class_name` 等历史债。
4. 每次批量清理后运行最小验证组合。
