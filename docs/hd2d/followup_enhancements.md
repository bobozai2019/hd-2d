# HD-2D Follow-up Enhancements

These items stay outside the default template until the baseline remains stable, formal Run flow passes, and performance budget allows expansion.

| Enhancement | Trigger condition |
|---|---|
| Segmented lighting shader | Only after current material/light budget remains stable across acceptance screenshots and run-loop tests. |
| Rim light shader | Only after character clarity remains stable under existing Glow/Fog settings. |
| Hit flash shader | Only after battle presentation needs exceed the current lightweight pulse/light feedback. |
| Advanced LUT pipeline | Only after base environment profiles stop changing and color grading needs repeatable production controls. |
| Volumetric fog | Only after thin fog planes prove insufficient and target hardware budget is re-evaluated. |
| More complex skill VFX | Only after default Run readability survives the current simple pulse/light samples. |
| Story camera staging | Only after gameplay camera controls and return-to-map behavior remain fully stable. |
| Batch asset import tools | Only after recurring content throughput needs justify tooling investment. |
